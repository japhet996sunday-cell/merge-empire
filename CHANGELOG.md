# Changelog

All notable changes to Merge Empire are documented here.

## [1.0.0] — 2026-08-21

### Added
- Complete vanilla JavaScript game architecture.
- Merge gameplay system with tier progression.
- Coin, tree, and gem item families.
- Six coin tiers.
- Six tree tiers.
- Five gem tiers.
- Production and idle-income systems.
- Offline progress calculation.
- Upgrade system.
- Achievement system.
- Mission system.
- Grid management and merge interactions.
- Local save and backup persistence.
- Responsive mobile-first interface.
- Light and dark theme support.
- Reduced-motion accessibility support.
- Web Audio API sound system.
- Merge and achievement animations.
- Item artwork for all playable item tiers.
- Framework-free DOM rendering architecture.

### Engineering
- ES6 module-based source organization.
- Centralized game-state mutation.
- Versioned save schema and migrations.
- Event-driven gameplay architecture.
- Object pooling for floating text effects.
- No external runtime dependencies.
- No external CDN dependencies.
- No build tool required.

### Packaging
- Production debug logging disabled.
- Proprietary license added.
- Project ignore rules added.
- Commercial packaging documentation added.
